1차시 개발환경 설치·첫 프로그램 실행

1. 파이썬에서 화면에 값을 출력하는 함수 이름은?
  print().
2. `print(3 + 5)`를 실행하면 무엇이 출력되나?
  8 (3+5=8. print는 계산 결과를 출력한다).
3. (O/X) 파이썬은 코드를 아래에서 위 순서로 실행한다.
  X — 파이썬은 위에서 아래 순서(인터프리터 방식)로 실행한다.
4. 컴파일 방식과 인터프리터 방식의 차이를 한 줄로 설명하라.
  컴파일=전체를 한 번에 번역 후 실행 / 인터프리터=한 줄씩 읽고 즉시 실행.


2차시 변수·자료형 기초와 형변환

1. `=` 기호의 의미는? (힌트: 수학의 `=`과 다르다)
  대입 — 오른쪽 값을 왼쪽 변수에 넣는다. 비교는 ==.
2. `type(3.14)`의 출력은?
  <class 'float'>.
3. (O/X) `"5" + 3`은 파이썬에서 정상 실행된다.
  X — str과 int는 +로 합칠 수 없다. TypeError 발생.
4. `int("30") + 10`의 결과는?
  40 (int("30") = 30, 30 + 10 = 40).
5. 다음 코드의 출력을 예상하라:
    ```python
    score = 95
    name = "홍길동"
    print(f"{name}의 점수: {score}점")
    ```
  홍길동의 점수: 95점 (f-string 안의 {변수}가 값으로 교체됨).
