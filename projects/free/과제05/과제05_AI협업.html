앞으로의 AI 선택 기준

  • 초기 단일 기능 구현 (AI A 방식): 목표가 명확하고 인터페이스 추가 작업이 필요한 경우, 계획된 요청 횟수 내에서 신속하게 코드를 작성하고 검사 항목을 나누어 인계 문서를 작성하는 방식이 유용합니다.
  • 회귀 검증 및 인계 작업 (AI B 방식): 이전 대화 이력 없이 인계 문서와 소스 코드만으로 현재 상태를 파악하고, 기존 기능의 손상(Side-effect) 없이 미완료된 검사 항목(8~10)을 정밀하게 수행할 때 효과적입니다.
  • 연속 작업 시 원칙: 기존에 잘 작동하는 코드 영역은 건드리지 않는 정밀 수정을 원칙으로 하며, 검증 도구(Fixture 모드 등)를 활용하여 단계별로 명확히 검증을 수행하는 모델을 선택하는 것이 안전합니다.
