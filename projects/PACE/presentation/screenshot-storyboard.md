# PACE 제출 자료: 기능별 화면 구성

현재 자료의 문제: 실제 화면 8종에 여러 기능을 묶어, 구현 범위가 충분히 드러나지 않는다. 설명 전용 페이지를 줄이고 아래 화면을 개별 캡처와 짧은 주석으로 설명한다.

## 디자인

- 밝은 배경 유지. 다크 모드는 앱 화면만 어둡게 표시.
- 한 페이지에 하나의 기능 또는 밀접한 작업 흐름.
- 실제 화면과 설명을 같은 페이지에 배치.
- 캡처 위에 2~3개 짧은 말풍선과 연결선. 버튼, 입력값, 목록을 가리지 않는다.
- 제목은 작고 선명하게, 설명은 기능과 실제 동작 중심으로 작성.
- 1920×1080 원본 캡처. 모달은 전체 화면과 확대 영역을 함께 사용.
- 실제로 캡처하지 않은 화면을 캡처 완료로 표시하지 않는다.
- 사용자 기록의 삭제·복사·인증 변경은 실행하지 않는다.

## 설명 전용으로 남길 내용

- 프로젝트 목적과 전체 흐름: 도입 1~2장
- 저장소 분리·revision 충돌 보호: 화면만으로 설명하기 어려운 기술 1장
- 구현 구조·검증 범위 및 제한: 마무리 1~2장

52개 항목은 기능 점검 목록이며 최종 페이지 수가 아니다. 가까운 기능은 같은 화면에 함께 주석을 달고, 서로 다른 입력 화면과 작업 흐름은 별도 페이지로 구성한다.
