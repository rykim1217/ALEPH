# PACE · 나의 앱 프로젝트

최종 자료는 25장입니다. 실제 앱 캡처와 기능 설명을 담았습니다.

- [최종 PPTX](완성본/PACE_나의앱프로젝트_최종발표자료_김라연.pptx): 약 2.9MB. Noto Sans KR을 사용하며 글꼴은 포함되어 있지 않습니다.
- 제출은 폰트와 배치가 고정되는 PDF를 사용합니다. PDF와 개인 백업·확인 안내 ZIP은 로컬 제출 폴더에서 별도로 제공합니다.
- 개인 학습 백업과 이전 파일, 대용량 미리보기는 공개 저장소에 포함하지 않습니다.

`content.json`은 자료 내용입니다. 앱 캡처는 PC와 태블릿·휴대폰 크기의 브라우저 화면을 사용했으며 실제 Safari 검증은 별도입니다. 백업 선택·검증 화면은 촬영했지만 실제 복원·초기화는 실행하지 않았습니다.
