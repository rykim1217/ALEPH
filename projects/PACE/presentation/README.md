# PACE 프로젝트 제출자료

[PowerPoint 자료](PACE-project.pptx)는 21장으로 구성한 제출용 프로젝트 소개입니다. 설명은 발표자 노트에 의존하지 않고 슬라이드 본문에 담았습니다.

- 개발 배경과 사용 흐름
- 달력, 학습 자료 등록·분석, 가능시간과 휴식일
- 시간·개수 기준 자동 분배와 미리보기·적용 보호
- 날짜별 학습 계획, 완료 기록과 예정시간
- 기기별 보기, 테마와 통합 설정
- 이메일 인증, 계정 저장소 분리와 revision 충돌 보호
- JSON 백업과 로컬·계정 초기화의 범위
- 기술 구성, 검증 결과와 남은 점검

화면은 1920×1080으로 캡처했습니다. 사용자가 공개 업로드를 허용한 로컬 학습 화면과 등록하지 않은 더미 강의 분석 미리보기를 사용합니다. 이메일·인증 정보·백업 JSON은 포함하지 않습니다.

2026-10-11 기준 자동 테스트 247개와 빌드를 통과했습니다. 실제 Safari 터치·키보드, 여러 기기 동기화와 실서버 데이터 초기화 검증은 완료로 주장하지 않습니다.

`content.json`은 슬라이드 본문 원본입니다. PPTX의 텍스트는 편집할 수 있으며 앱 화면은 이미지로 삽입했습니다.
