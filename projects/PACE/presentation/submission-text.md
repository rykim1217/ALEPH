# 최종 제출 입력용 문구

## 이번에 만든 것
PACE는 자격증 학습 일정 관리 웹앱입니다. 강의·교재·기출문제 등 학습 자료를 등록하고, 공부 가능한 시간과 휴식일을 반영해 날짜별 계획을 만들며, 완료 기록과 진행률을 관리합니다. 계정 동기화, JSON 백업, 화면 설정도 지원합니다.

## 확인하는 방법 · 3단계 이내
1. 결과물 URL에 접속한 뒤 ‘로그인 없이 시작하기’를 선택합니다.
2. ‘설정 → 데이터 관리 → JSON 파일 선택’에서 첨부한 백업을 선택하고, 데이터 요약과 동의 항목을 확인한 뒤 ‘백업 가져오기’를 실행합니다. 기존 기록이 없는 브라우저에서 확인해 주세요.
3. ‘일정·학습 항목·학습 계획’에서 날짜별 계획, 개별 예정시간, 완료 기록과 진행률을 확인합니다. ‘설정 → 화면’에서는 테마와 달력 시작 요일을 변경할 수 있습니다.

## 바뀐 점과 그 이유
자료 유형별 등록과 수정 가능한 미리보기로 반복 입력을 줄였습니다. 실제 가능시간·휴식일을 반영하는 자동 분배와 날짜별 예정시간으로 계획의 가독성을 높였습니다. 테마·요일 설정·기기별 보기로 사용 환경에 대응하고, 로컬·계정 기록 분리와 확인 절차·충돌 검사로 데이터 보호를 보완했습니다.

## AI에게 맡긴 일과 내가 판단한 일
AI에게 기능 구현, 코드 검토와 오류 수정, 테스트·빌드 확인, README와 제출자료 초안 작성을 맡겼습니다. 저는 실제 학습에 필요한 기능, 삭제·복사 범위와 동의 절차, 화면 디자인과 문구를 판단했습니다. 직접 사용하며 캡처로 문제를 전달하고, 태블릿 3일 보기처럼 사용성을 기준으로 수정 방향을 결정했습니다.

## 다음에 할 일
실제 iPad·iPhone Safari에서 터치·스크롤·키보드 동작을 점검하고, 집과 학원에서 계정 동기화가 이어지는지 확인할 계획입니다. 터치 환경에서 개별 예정시간을 확인하는 안내도 개선하고 싶습니다.
