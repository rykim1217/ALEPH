# PACE · 자격증 학습 일정 관리 웹앱

PACE는 시험일까지 남은 학습량과 공부 가능한 날짜를 바탕으로 학습 일정을 계획하고, 실제 학습 진도를 기록하는 웹앱입니다. 여러 자격증을 준비할 때 시험 일정, 학습 항목, 완료 기록과 일별 계획을 한 화면에서 관리하는 것을 목표로 합니다.

강의처럼 예상 시간이 있는 학습과 교재처럼 시간이 정해지지 않은 학습을 함께 지원합니다. 자동 분배 결과는 먼저 미리보기로 검토하고, 사용자가 적용할 때만 실제 일정에 반영합니다.

- 배포 주소: [my--pace.vercel.app](https://my--pace.vercel.app)
- 저장소: [rykim1217/ALEPH](https://github.com/rykim1217/ALEPH)
- 프로젝트 경로: `projects/PACE`
- 기술: HTML, CSS, JavaScript ES Modules, 브라우저 localStorage
- 서버 구성: 로컬 개발용 Node.js 정적 서버 / 배포용 정적 파일

## 현재 구현된 기능

### 자격증과 시험 일정

- 자격증 이름과 시험 날짜를 추가·수정·삭제합니다. 시험 날짜는 선택 입력입니다.
- 자격증별 세부 목표와 목표 날짜를 관리하고 달력에 표시합니다.
- 자격증 선택 목록은 아직 지나지 않은 시험을 먼저, 시험일이 빠른 순으로 표시하며 지난 시험은 구분해서 표시합니다.
- 자동 기본 선택에 날짜 우선순위를 사용하고 사용자가 직접 선택한 자격증은 유지합니다. 시험일이 지났다는 이유로 학습을 자동 완료하지 않습니다.
- 달력에서 전체 일정 또는 자격증별 일정을 확인하고 개인 일정을 추가·수정·삭제합니다.

### 학습 가능 시간과 휴식일

- 자격증별 학습 시작일, 선택적인 종료일과 학습 가능 시간을 저장합니다.
- 매일 동일, 평일/주말, 요일별 시간 설정을 지원합니다.
- 정기 휴식 요일과 특정 날짜의 휴식·학습 시간 예외를 설정합니다.
- 날짜 예외, 정기 휴식, 기본 시간 순서로 규칙을 적용합니다. 미설정 시간과 0분은 구분합니다.
- 날짜 상세 화면에서도 해당 날짜의 학습 시간을 변경할 수 있습니다.

### 학습 항목 등록과 관리

- 강의, 교재, 기출문제, 모의고사, 복습, 기타 유형을 지원합니다.
- 강의 목차를 붙여넣어 번호·제목·영상 길이를 분석하고 등록 전에 결과를 수정하거나 일부 항목만 선택합니다.
- 교재는 과목·장 제목을 구조로 구분하고 소단원을 학습 항목으로 분석합니다. 한 과목 또는 과목 구분이 없는 목차는 원본 번호를 유지하고, 여러 과목이면 필요한 경우 과목 번호를 추가합니다. 이미 계층이 있는 번호는 중복 확장하지 않습니다.
- 교재 예상 시간은 선택 입력입니다. 불명확한 목차는 분석 결과를 직접 확인하고 수정한 후 등록합니다.
- 기출문제는 연도·회차, 모의고사는 회차 범위로 여러 항목을 생성합니다.
- 등록한 항목의 제목·번호·분류·시간을 수정하고 선택 삭제할 수 있습니다. 분류 순서와 색상도 관리합니다.
- 중복으로 판단한 항목은 등록 시 건너뜁니다. 텍스트 분석만으로 기존 항목을 변경하지 않습니다.

### 진도와 완료 기록

- 항목별 완료 체크와 취소를 지원하고, 자격증·분류별 완료 개수와 진행률을 표시합니다.
- 오늘의 학습 카드, 달력 날짜 상세와 학습 계획 화면에서 날짜별 배정 항목을 확인합니다.
- 학습 계획에서는 주간·월간 일정을 확인하고 항목의 배정 날짜를 수동 변경할 수 있습니다.
- 강의 배속은 학습 계획의 예상 시간 계산에 사용합니다. 실제 영상 재생 기능은 없으며 교재 등 다른 유형에는 배속을 적용하지 않습니다.

### 자동 학습 일정 분배

**학습 계획 → 자동 분배**에서 설정하고 결과를 확인합니다.

- 예상 시간이 있는 항목은 날짜별 학습 가능 시간을 기준으로 분배합니다.
- 예상 시간이 없는 항목은 공부 가능한 날짜에 개수 기준으로 분배합니다. 임의의 예상 시간을 저장하지 않으며 일일 개수 한도를 자동 계산하거나 직접 설정할 수 있습니다.
- 시간 기준 항목과 개수 기준 항목을 같은 날짜에 배치할 수 있습니다. 시간 합계에는 실제 예상 시간이 있는 항목만 포함합니다.
- 순차 학습은 앞 분류의 일반 항목을 모두 배치한 뒤 다음 분류로 진행합니다. 병행 학습은 하루 최대 2개 분류를 사용합니다.
- 설정한 분류 우선순위와 분류 내 순서를 따르고 완료 항목을 다시 배치하지 않습니다. 휴식일과 학습 시간이 0인 날짜는 제외하며 날짜별 예외 시간을 반영합니다.
- 세부 목표를 이정표로 설정하고 목표일까지 완료할 분류를 연결합니다. 미리보기에서 충족 여부와 예상 완료일을 확인합니다.
- 시험 직전 학습 항목 관리 패널에서 검색·분류 필터로 여러 항목을 선택하고 각 항목의 시험 며칠 전인지 지정합니다. 시험 날짜가 바뀌면 지정일도 다시 계산합니다.
- 시험 직전 지정 항목은 일반 대상에서 분리하여 지정 날짜에 우선 배치합니다. 지정 날짜의 시간·휴식·분류 제한으로 배치하지 못하면 임의로 다른 날짜에 이동하지 않고 미배치로 안내합니다.

### 미리보기와 실제 일정 적용

- 이정표 결과, 분배 요약, 날짜별 항목과 분류 색상 막대, 미배치 항목을 표시합니다.
- 날짜별 상세와 미배치 목록은 접고 펼칠 수 있습니다. 개수 기준 항목에 가짜 소요 시간을 표시하지 않습니다.
- 미리보기를 닫는 것만으로 실제 일정은 바뀌지 않습니다. 분배 설정 저장과 실제 일정 적용은 별도 동작입니다.
- **분배 적용**을 누르면 미리보기에서 배치된 항목의 날짜를 실제 학습 일정에 반영합니다. 해당 항목의 기존 배정 날짜는 새 날짜로 변경될 수 있습니다.
- 미배치 항목의 기존 날짜와 완료 기록은 유지합니다. 같은 항목을 새로 생성하지 않아 반복 적용으로 항목이 중복되지 않습니다.
- 미리보기 이후 학습 데이터나 계산 조건이 달라지면 다시 계산하도록 안내합니다.

### JSON 백업과 복원

왼쪽 **설정**의 **백업 파일 가져오기** 화면에서 백업 다운로드와 JSON 복원을 사용할 수 있습니다.

1. 필요한 경우 **현재 데이터 백업 다운로드**로 현재 브라우저 데이터를 저장합니다. 다운로드는 선택 사항이며 기존 저장값을 변경하지 않습니다.
2. **JSON 파일 선택**으로 PACE 백업을 선택합니다.
3. 검증 결과와 자격증별 항목 수, 전체 항목·완료·날짜 배정·개인 일정 수를 확인합니다.
4. 가져오기 동의를 체크한 후 **백업 가져오기**를 누릅니다. 성공하면 화면을 다시 불러옵니다.

`pace-local-backup` 버전 1 형식의 JSON을 지원하며 파일 크기는 최대 20MB입니다. 저장값 원문과 해석된 항목 목록을 포함하는 기존 내보내기 형식과 호환됩니다. 파일 형식, ID와 자격증 연결, 완료 상태, 날짜와 설정 등을 검증합니다.

파일 선택과 미리보기만으로 데이터가 바뀌지 않습니다. 가져오기를 실행하면 기존 `pace.*` 데이터를 선택한 백업 내용으로 **교체**하며 두 데이터를 병합하지 않습니다. 다른 앱의 저장 키는 건드리지 않습니다. 동시 변경을 감지하면 중단하고 저장 실패 시 이전 값으로 되돌리기를 시도합니다.

새 브라우저에서도 유효한 백업 파일로 복원할 수 있습니다. 개인 기록을 포함하는 JSON은 GitHub나 공개 배포 파일에 넣지 말고 별도로 보관·전달하세요. 브라우저에서 다운로드 요청은 할 수 있지만 실제 파일 저장 여부는 확인할 수 없으므로 다운로드 폴더를 직접 확인하세요.

## 실행 방법

Node.js 20 이상을 사용합니다. 외부 npm 의존성이 없어 별도 패키지 설치 없이 실행할 수 있습니다.

```powershell
cd C:\ALEPH\projects\PACE
npm run dev
```

기본 주소는 `http://127.0.0.1:5173`이며 종료는 `Ctrl+C`입니다. `npm start`도 같은 서버를 실행합니다. 다른 포트를 사용하려면 다음과 같이 설정합니다.

```powershell
$env:PORT = '5174'
npm run dev
```

npm 없이 `node server.js`로도 실행할 수 있습니다. 로컬 서버는 소스 변경을 감지하여 화면을 새로고침하며 배포용 백엔드가 아닙니다.

## 테스트와 빌드

```powershell
npm test
npm run build
```

npm 없이도 같은 작업을 실행할 수 있습니다.

```powershell
node --test
node scripts/build.js
```

테스트는 Node.js 기본 테스트 러너를 사용하며 날짜 계산, 등록·파싱, 완료 기록, 설정, 시간·개수 분배, 이정표, 시험 직전 배치, 일정 적용과 백업 검증·복원을 검사합니다. 저장 관련 테스트는 가상 데이터와 테스트용 저장소를 사용합니다. 자동 테스트가 실제 브라우저 UI 검증을 모두 대신하지는 않습니다.

빌드는 기존 `dist`를 다시 만들고 `scripts/build.js`에 명시된 실행 파일만 복사합니다. README, 테스트 fixture, 계획 문서, 참고 이미지, 로컬 백업과 개발 서버는 배포 결과물에 포함하지 않습니다.

| 항목 | 설정 |
| --- | --- |
| GitHub 저장소 | `rykim1217/ALEPH` |
| 배포 브랜치 | `main` |

`vercel.json`에도 빌드 명령과 출력 경로를 지정합니다. 연결된 GitHub 브랜치의 변경으로 자동 배포하며 Vercel은 `dist`의 정적 파일을 제공합니다. 별도 API 서버나 데이터베이스는 없습니다. 폰트는 jsDelivr에서 불러옵니다.

`dist/`, `node_modules/`, `.vercel/`, `.local-backups/`는 Git에서 제외합니다. 백업 JSON은 저장소 밖이나 `.local-backups/`에 보관하세요.

## 저장 방식과 데이터 보존

데이터는 브라우저 localStorage의 `pace.*` 키에 저장합니다.

| 키 | 주요 내용 |
| --- | --- |
| `pace.certifications.v1` | 자격증, 시험 날짜, 세부 목표와 이정표 |
| `pace.study-plans.v1` | 학습 항목, 완료 기록, 날짜 변경, 분류 설정 |
| `pace.availability.v2` | 자격증별 학습 가능 시간, 휴식일과 날짜 예외 |
| `pace.planning-settings.v1` | 자격증별 강의 계획 배속 |
| `pace.distribution-settings.v1` | 분배 방식·우선순위·개수 한도·시험 직전 설정 |
| `pace.personal-events.v1` | 개인 일정 |

과거 학습 가능 시간 형식인 `pace.availability.v1`과 저장된 범위형 학습 항목을 읽는 호환 로직도 유지합니다. 개인 목차나 완료 기록을 공개 소스에서 자동 등록하거나 복원하지 않으며 빈 브라우저에 개인 기록이나 체험용 데이터를 자동 생성하지 않습니다.

저장은 브라우저와 사이트 주소별입니다. 로컬 주소, 포트가 다른 주소와 Vercel 주소는 저장소가 서로 다릅니다. 다른 브라우저·기기에도 자동 공유되지 않습니다. 사이트 데이터 삭제나 브라우저 변경에 대비해 JSON 백업을 보관하세요.

## 향후 작업

로그인, 계정별 서버 저장과 기기 간 데이터 동기화는 아직 구현하지 않았습니다. 현재는 브라우저 저장과 JSON 백업을 사용합니다. 학습 변경에 따른 상시 자동 재분배도 제공하지 않으며, 사용자가 자동 분배를 다시 실행하고 미리보기를 적용하는 방식입니다.
