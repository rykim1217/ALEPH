# PACE · 1차 중간 점검

학습 일정 관리 웹앱의 데스크톱 첫 화면입니다. `plan.md`의 확정된 구조와 색상을 기준으로 제작했습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더의 터미널로 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

```powershell
node server.js
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 종료는 Ctrl+C입니다. npm이 있는 환경에서는 `npm run dev`도 가능합니다.

## 검증

```powershell
node --test
```

## Vercel 배포

- GitHub 저장소: `rykim1217/ALEPH`
- Root Directory: `projects/PACE`
- Framework Preset: `Other`
- Build Command: `npm run build`
- Output Directory: `dist` (Root Directory 기준)

`npm run build`는 `index.html`과 실행에 필요한 `src/styles.css`, `src/app.js`, `src/calendar.js`, `src/data.js`, `src/certifications.js`, `src/color-palette.js`, `src/availability.js`만 `dist`에 복사합니다. 원본 파일 내용과 경로는 유지됩니다. 빌드할 때 이전 출력은 삭제하므로 오래된 파일이 남지 않습니다. README, 계획 문서, 테스트, 참고 이미지, 로컬 서버 및 빌드 스크립트는 공개 출력에 포함하지 않습니다. 외부 npm 패키지와 배포용 서버는 필요하지 않으며, Vercel은 `dist`의 정적 파일을 제공합니다. 폰트는 기존과 같이 jsDelivr에서 불러옵니다.

`dist`는 생성 파일이므로 Git에 포함하지 않습니다. `vercel.json`에도 빌드 명령과 출력 경로를 지정했습니다. 로컬에서는 `node scripts/build.js`로도 동일한 출력을 만들 수 있습니다.

- 이전/다음 달 버튼으로 월 이동 및 연도 경계를 확인합니다.
- 오늘 버튼으로 현재 월과 오늘 날짜 선택 상태로 돌아옵니다.
- 날짜를 클릭하여 학습 가능시간, 예정 학습, 총 시간, 특별 일정을 확인합니다.
- 팝업은 닫기 버튼, Esc, 바깥 영역 클릭으로 닫습니다.
- 자격증 필터를 바꾸면 오늘 요약과 캘린더가 함께 바뀝니다.
- 등록한 시험일과 개인 일정만 표시하며 예시 학습·목표·휴식일을 자동 생성하지 않습니다.
- 메뉴 및 날짜별 시간 변경 진입은 개발 예정 안내만 표시하며 데이터를 수정하지 않습니다.

## 구조와 후속 작업

- `src/calendar.js`: 날짜 계산과 표시. 자동 테스트 포함.
- `src/data.js`: 명시적으로 전달된 실제 학습 항목·목표·날짜별 학습 가능 시간과 자격증·개인 일정을 요약하는 계층. 기본값은 빈 목록과 미설정입니다.
- `src/data.js`의 `studyColors`: 사이드바·달력·상세 팝업이 공유하는 강의/문제풀이/복습 색상.
- `src/app.js`: 화면 상태, 렌더링, 사용자 동작.
- `src/styles.css`: 원본 참고 이미지의 사이드바·달력·팝업 배치, Pretendard 폰트, 작은 화면 대응.
- `server.js`: 로컬 실행용 정적 서버. 배포용 백엔드가 아닙니다.

2차의 첫 기능으로 자격증 추가·수정·삭제를 구현했습니다. 사이드바의 **시험 설정**에서 이름과 선택 입력인 시험 날짜를 설정할 수 있습니다. 자격증 구분 색상은 빨간색으로 고정됩니다. 시험일이 없으면 D-day와 달력 시험일 표시는 생략됩니다. 반복되는 예시 학습 생성은 제거했습니다. 학습 항목이 없으면 안내 문구와 총 예정시간 `—`, 가능 시간이 없으면 `미설정`을 표시합니다. 저장된 자격증·개인 일정은 초기화하지 않습니다. 기존 저장 색상도 수정 시 유지합니다.

자격증은 `pace.certifications.v1`, 개인 일정은 `pace.personal-events.v1`이라는 별도 localStorage 키에 저장합니다. 자격증을 수정하거나 삭제해도 개인 일정은 유지됩니다. 모두 삭제한 자격증 목록도 새로고침 후 빈 상태로 유지됩니다. 저장 범위는 브라우저와 사이트 주소별이며 다른 기기나 로컬/Vercel 사이에 자동 동기화되지 않습니다. `src/certifications.js`에 입력 검증·저장·추가·수정·삭제 로직과 `tests/certifications.test.js`에 테스트가 있습니다.

학습 항목 등록, 자동 배분·학습 기록·재배분, 데이터베이스와 로그인은 후속 작업입니다.

## 디자인 참고

프로젝트의 `design-reference.png`를 화면 구조와 배치 기준으로 삼았습니다. 원본의 보라색 바탕 대신 웜 라이트그레이(`#F1F0F2`)를 적용하고, 월요일 시작 캘린더와 학습 유형별 색상 점 및 선택 날짜 옆 상세 팝업으로 구성했습니다. 시험 상자에는 등록된 시험일 기준 D-day를 표시합니다. 임의 학습 시간·목표일·휴식일은 표시하지 않습니다. 달력은 브라우저 뷰포트 높이에 맞추어 5주·6주 모두 표시합니다.

색상 팔레트는 학습 항목 추가·수정 화면에서 사용할 예정이며 현재 자격증 관리에서는 표시하지 않습니다. 기본·세부 팔레트는 데스크톱에서 한 줄로 배치하고 모바일에서는 줄을 나눕니다. 시험 배지는 기존 분홍 배경·붉은 글씨·테두리 없는 디자인을 유지합니다.

## 학습 가능 시간 설정

사이드바의 **학습 가능시간**에서 매일 동일·평일/주말·요일별 시간을 설정합니다. 비어 있는 시간은 미설정이며 0분과 구분합니다. 정기 휴식 요일과 특정 날짜 예외를 설정할 수 있습니다. 날짜 예외 → 정기 휴식 → 기본 시간 순서로 적용하며, 예외를 삭제하면 기본 규칙으로 돌아갑니다. 날짜 상세의 **변경** 또는 **이 날만 학습시간 변경**으로 해당 날짜 예외에 바로 진입합니다. 예외 추가/수정 반영 후 **설정 저장**을 눌러 적용합니다. 취소하면 저장되지 않습니다.

`src/availability.js`가 `pace.availability.v1` 키만 사용합니다. 자격증·개인 일정·완료 기록 키는 변경하지 않습니다. 기본 시간과 휴식일을 변경해도 날짜 예외는 유지됩니다. 모든 자격증이 하루 가능 시간을 공유하며 필터별로 합산하지 않습니다. 저장 시 오늘 카드·월간/연간 달력·날짜 상세를 갱신하지만 학습 항목이나 자동 일정을 생성하지 않습니다. 3단계 제출 계획의 2차 시간 설정 범위입니다.


## 개인 기록과 기존 데이터 보존

앱은 개인 목차나 완료 기록을 소스에서 자동 등록·복원·삭제하지 않습니다. 기존 `pace.*` localStorage의 ID, 날짜, 완료 기록과 설정을 그대로 읽습니다. 빈 브라우저에 개인 기록이나 샘플을 자동 생성하지 않습니다.

과거 범위 형식은 저장된 `records.ranges`만 해석합니다. `materializeSavedStudy`는 같은 ID와 완료 상태를 유지하는 일반 항목을 만들고 변환 전후 목록을 검증합니다. 영구 변환은 외부 백업을 확인한 경우에만 `migrateSavedStudy(storage, {backupConfirmed:true})`로 진행하며, 원문을 `pace.before-catalog-migration.v1`에 보관하고 동시 변경·기존 백업 충돌 시 저장을 중단합니다. 초기화에서는 백업 미확인 데이터를 변환해 저장하지 않습니다.

`createPaceBackup`의 JSON에는 저장값 원문(`rawStorage`)과 해석된 항목(`resolvedStudyItems`)이 들어 있습니다. 개인 백업과 과거 개인 소스는 `.local-backups/` 또는 저장소 밖에 보관하며 Git과 공개 빌드에 포함하지 않습니다. 복구에는 원본 백업을 사용하고, 먼저 현재 값과 원본 ID·완료 상태를 검증해야 합니다. 샘플 체험 모드는 제공하지 않습니다.


## 백업 파일 가져오기

왼쪽 **설정**에서 `pace-local-backup` 버전 1 JSON 파일을 선택합니다. 파일은 20MB까지 허용하며 자격증·항목·완료·날짜·설정과 원문/해석 목록의 일치 여부를 검사합니다. 자격증별 항목 수와 전체 완료 수를 확인한 후 가져오기 동의를 체크합니다.

**현재 데이터 백업 다운로드**는 선택 사항입니다. 기존 데이터가 있어도 유효한 JSON 파일을 선택하고 교체에 명시적으로 동의하면 가져올 수 있습니다. 가져오기는 기존 `pace.*` 저장값을 선택한 백업 내용으로 교체하며 다른 앱의 키는 건드리지 않습니다. 파일을 선택하거나 미리보기만 보는 동안에는 저장값이 변경되지 않습니다. 동시 변경 시 적용을 중단하고, 저장 실패 시 원래 값으로 되돌리기를 시도합니다. 성공 후 화면을 다시 불러옵니다.

개인 기록이 있는 백업 JSON은 GitHub나 공개 정적 빌드에 넣지 마세요. 채점자에게 필요한 백업은 별도 제출 파일로 전달합니다.
