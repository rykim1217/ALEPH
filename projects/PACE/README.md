# PACE · 1차 중간 점검

학습 일정 관리 웹앱의 데스크톱 첫 화면입니다. `plan.md`의 확정된 구조와 색상을 기준으로 제작했습니다.

## 실행

Node.js 20 이상에서 프로젝트 폴더의 터미널로 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

```powershell
node server.js
```

브라우저에서 http://127.0.0.1:5173 을 엽니다. 종료는 Ctrl+C입니다. npm이 있는 환경에서는 `npm run dev`도 가능합니다.

## 검증

```powershell
node --test
```

## Vercel 배포

- GitHub 저장소: `rykim1217/ALEPH`
- Root Directory: `projects/PACE`
- Framework Preset: `Other`
- Build Command: `npm run build`
- Output Directory: `dist` (Root Directory 기준)

`npm run build`는 `index.html`과 실행에 필요한 `src/styles.css`, `src/app.js`, `src/calendar.js`, `src/data.js`만 `dist`에 복사합니다. 원본 파일 내용과 경로는 유지됩니다. 빌드할 때 이전 출력은 삭제하므로 오래된 파일이 남지 않습니다. README, 계획 문서, 테스트, 참고 이미지, 로컬 서버 및 빌드 스크립트는 공개 출력에 포함하지 않습니다. 외부 npm 패키지와 배포용 서버는 필요하지 않으며, Vercel은 `dist`의 정적 파일을 제공합니다. 폰트는 기존과 같이 jsDelivr에서 불러옵니다.

`dist`는 생성 파일이므로 Git에 포함하지 않습니다. `vercel.json`에도 빌드 명령과 출력 경로를 지정했습니다. 로컬에서는 `node scripts/build.js`로도 동일한 출력을 만들 수 있습니다.

- 이전/다음 달 버튼으로 월 이동 및 연도 경계를 확인합니다.
- 오늘 버튼으로 현재 월과 오늘 날짜 선택 상태로 돌아옵니다.
- 날짜를 클릭하여 학습 가능시간, 예정 학습, 총 시간, 특별 일정을 확인합니다.
- 팝업은 닫기 버튼, Esc, 바깥 영역 클릭으로 닫습니다.
- 시험 계획 선택을 바꾸면 오늘 요약과 캘린더 예시가 함께 바뀝니다.
- 현재 달 23일(첫 시험 계획)은 목표일, 다음 달 14일은 시험일, 일요일은 휴식일입니다.
- 메뉴 및 날짜별 시간 변경 진입은 개발 예정 안내만 표시하며 데이터를 수정하지 않습니다.

## 구조와 후속 작업

- `src/calendar.js`: 날짜 계산과 표시. 자동 테스트 포함.
- `src/data.js`: 실제 모델로 대체할 예시 데이터 공급 계층. 예시 기준일은 브라우저의 현재 날짜입니다.
- `src/data.js`의 `studyColors`: 사이드바·달력·상세 팝업이 공유하는 강의/문제풀이/복습 색상.
- `src/app.js`: 화면 상태, 렌더링, 사용자 동작.
- `src/styles.css`: 원본 참고 이미지의 사이드바·달력·팝업 배치, Pretendard 폰트, 작은 화면 대응.
- `server.js`: 로컬 실행용 정적 서버. 배포용 백엔드가 아닙니다.

2차에서는 시험·학습 항목·시간 설정 폼과 데이터 모델을 추가하고 예시 공급 계층을 실제 입력 데이터로 교체합니다. 최종 단계에서는 자동 배분·학습 기록·재배분·영구 저장·배포를 구현합니다. 현재 자동 배분, 실제 등록/기록/저장, 데이터베이스, 로그인은 없습니다.

## 디자인 참고

프로젝트의 `design-reference.png`를 화면 구조와 배치 기준으로 삼았습니다. 원본의 보라색 바탕 대신 웜 라이트그레이(`#F1F0F2`)를 적용하고, 월요일 시작 캘린더와 학습 유형별 색상 점 및 선택 날짜 옆 상세 팝업으로 구성했습니다. 시험 상자에는 예시 시험일 기준 D-day를 표시합니다. 예시에서는 매달 둘째·넷째 일요일을 휴식일로 두고, 나머지 일요일에는 예시 학습을 배정합니다. 달력은 브라우저 뷰포트 높이에 맞추어 5주·6주 모두 표시합니다.
