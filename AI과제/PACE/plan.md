# plan.md

## 1. 프로젝트 목표

자격증·시험 준비 학습자를 위한 학습 관리 앱을 만든다.

시험일까지 남은 학습량과 사용자의 학습 가능시간을 바탕으로 일별 학습 계획을 자동 생성하고, 실제 학습 결과에 따라 남은 일정을 자동 재배분한다.

초기 테스트는 정보처리기사 실기를 기준으로 진행하지만, 특정 시험이나 학습 방식에 종속되지 않는 구조를 목표로 한다.

> 현재 상태: 기획을 완료하고 단계별 구현을 시작한다. 아래의 개발 단계는 제출 순서이며, 기존 핵심 기능 및 자동 배분 규칙을 변경하지 않는다.

---

## 1-1. 앱 이름 및 화면 디자인 (2026-10-09 확정)

- 앱 이름: **PACE**
- 기준 화면: 사용자가 확정한 데스크톱 월간 캘린더 시안. 화면 구조와 배치는 유지한다.
- 왼쪽: PACE 로고, 오늘 날짜, 오늘의 학습 카드(학습 단계·학습 가능시간·배정 항목·총 예정시간), 일정·학습 항목·학습 가능시간·시험 설정·설정 메뉴.
- 오른쪽: 시험 선택, 월 이동 및 오늘 버튼, 월간 캘린더, 학습·목표·시험·휴식일 범례.
- 날짜 클릭 시 해당 날짜의 학습 가능시간, 예정 학습, 특별 일정, 날짜별 학습시간 변경 진입을 표시한다.
- 기본 배경 `#F7F8FA`, 카드 `#FFFFFF`, 선택 영역 `#E9EDF2`, 본문 글자 `#242938`, 로고는 짙은 차콜 그레이.
- 보라색은 전체 배경이나 그림자에 넓게 사용하지 않는다. 학습 유형을 구분하는 보라·파랑·초록은 유지한다. 시험은 코랄, 목표는 베이지·오렌지 계열을 유지한다.
- 색상 변경은 레이아웃 변경을 의미하지 않는다. 초기에는 데스크톱 웹 화면을 우선한다.

## 1-2. 3단계 개발·제출 계획 (2026-10-09 추가)

이 구분은 ALEPH Studio의 **중간 점검 1차 → 중간 점검 2차 → 최종 제출**에 대응한다. 각 단계는 이전 단계의 결과물을 보존하면서 기능을 확장한다. 실제 제출 전에는 해당 단계의 작동을 확인하고 결과물 URL과 확인 절차를 준비한다.

### 1차 중간 점검 — 첫 화면과 캘린더

- PACE 첫 화면 UI 및 월간 캘린더 구현
- 월 이동·오늘 버튼·날짜 선택 기능
- 선택 날짜의 상세 팝업 열기·닫기
- 오늘의 학습 카드 및 일정 범례 표시
- 화면 검증을 위한 예시 데이터 사용 가능. 예시 데이터는 실제 저장·자동 배분 기능으로 오해되지 않게 구분한다.
- **제외:** 학습 데이터의 실제 등록·영구 저장, 자동 일정 배분, 학습 결과 기록

### 2차 중간 점검 — 시험·학습 항목·시간 설정

- 시험명·시험일 등록 및 수정, 학습 유형 선택
- 강의·문제풀이·복습 항목 등록·수정·삭제, 우선순위 및 선택적 목표 완료일
- 강의 목록 텍스트 붙여넣기·기본 파싱·검토 후 일괄 등록
- 요일별 학습 가능시간과 특정 날짜 예외 시간 설정
- 1차에서 만든 화면에 입력한 정보가 반영되는지 검증
- **제외:** 완성형 자동 배분·자동 재배분 엔진 (최종 단계에서 구현)

### 최종 제출 — 계획 생성·기록·재배분·배포

- 이 문서의 10~14절에 정의된 자동 배분·재배분 규칙 구현
- 오늘 계획의 일회성 수정, 실제 학습 결과 기록, 남은 학습량 계산
- 시간 부족 및 미배정 학습량 표시
- 데이터 저장 및 재접속 시 복원, 조건이 변경되지 않은 계획의 재사용
- 주요 흐름 테스트, 오류 수정, 로그인 없이 접근 가능한 결과물 배포 및 제출 검증

### 공통 작업 원칙

- 구현 시 현재 제출 단계에 해당하는 기능을 우선한다. 다음 단계의 기능을 임의로 선구현하지 않는다.
- UI에 표시된 버튼과 동작이 실제 기능인지 예시·미구현 상태인지 구분한다.
- 기존 프로젝트 파일과 기능을 보존하고, 수정 사항을 확인 가능한 단위로 반영한다.
- 본 문서 2~19절의 기능 정의·제외 범위·동작 규칙이 상세 요구사항의 기준이다.

## 4. 학습 유형

시험 계획을 등록할 때 사용자가 필요한 학습 유형을 복수로 선택한다.

시험 종류가 학습 유형을 자동으로 결정하지 않는다.

초기 지원 유형:

- 강의
- 문제풀이
- 복습

선택한 유형만 해당 시험 계획에서 사용한다.

초기 버전에서는 선택한 유형을 이후 비활성화하는 기능은 제공하지 않는다.

## 5. 강의

### 등록 데이터

- 강의명
- 강의 순서 또는 회차
- 예상 소요시간
- 우선순위
- 선택적 목표 완료일

### 등록 방식

- 강의별 개별 등록
- 강의 목록 복사·붙여넣기
- 일반 텍스트 파싱으로 강의명과 시간 추출
- 파싱 결과 미리보기
- 사용자의 확인·수정 후 일괄 등록

AI 기반 인식은 사용하지 않는다.

### 학습 기록

사용자는 다음 중 편한 방식으로 기록한다.

- 강의 완료
- 진행률
- 학습한 시간

실제 시청시간 입력은 선택 사항이다.

강의를 완료하지 못한 경우 진행률 또는 학습시간을 저장하고 이후 일정에서 이어서 배정한다.

### 계획 단위

기본적으로 강의 1개 단위로 계획한다.

## 6. 문제풀이

### 등록 데이터

- 문제풀이 항목명
- 전체 문제 수
- 예상 소요시간 또는 예상 문제량
- 우선순위
- 선택적 목표 완료일

### 학습 기록

기본 기록값은 완료한 문제 수다.

선택적으로 다음을 기록할 수 있다.

- 정답 수
- 오답 수
- 실제 소요시간

정답 수와 오답 수는 초기 계획 배분에 필수로 사용하지 않는다.

### 계획 단위

문제 수 단위로 계획한다.

사용자가 필요하면 최소 문제 수를 설정할 수 있다.

예:

```text
최소 5문제
```

## 7. 복습

### 등록 데이터

- 복습 항목명
- 회당 예상 소요시간
- 총 복습 횟수
- 우선순위
- 선택적 목표 완료일

총 복습 횟수의 기본값은 1회다.

### 학습 기록

- 복습 완료 여부
- 완료한 회차 수
- 실제 학습시간

예상 소요시간과 실제 소요시간은 선택적으로 기록한다.

### 반복 복습

총 복습 횟수를 지정하면 각 회차를 남은 학습량으로 계산한다.

예:

```text
회당 20분, 총 3회
진행량: 0/3 → 1/3 → 2/3 → 3/3
```

초기 버전에서는 반복 회차를 가능한 학습일에 배정한다.

다음 기능은 이후로 미룬다.

- 1일·7일·30일 간격 자동 설정
- 학습 완료 후 복습 자동 생성
- 복습 주기 자동 최적화

### 계획 단위

시간 단위로 계획한다.

## 8. 공통 학습 항목 설정

모든 학습 항목은 다음 정보를 가질 수 있다.

- 항목명
- 학습 유형
- 예상 학습량 또는 예상 소요시간
- 우선순위
- 선택적 목표 완료일
- 진행량
- 선택적 실제 소요시간

우선순위는 다음 세 단계로 한다.

- 높음
- 보통
- 낮음

목표 완료일이 없으면 시험일까지 완료하는 것을 기본값으로 사용한다.

실제 소요시간은 저장하지만, 한 번의 기록으로 예상 소요시간을 자동 변경하지 않는다.

---

## 9. 학습 가능시간 설정

### 요일별 기본시간

사용자는 요일별 학습 가능시간을 설정한다.

예:

```text
월~금: 2시간
토요일: 4시간
일요일: 0시간
```

특정 요일을 0시간으로 설정하면 정기 휴식일로 사용할 수 있다.

주 1회 휴식일을 강제로 설정하지 않는다.

### 특정 날짜 예외

특정 날짜에는 기본시간과 다른 시간을 지정할 수 있다.

- 학습 불가: 0시간
- 시간 축소: 1시간
- 추가 학습: 5시간

예외 시간은 여행, 약속, 일정 등으로 활용한다.

특정 날짜의 시간이 변경되면 해당 날짜 이후의 남은 계획을 재계산한다.

---

## 10. 자동 배분 규칙

계획 생성 시 다음 정보를 사용한다.

- 남은 학습량
- 예상 소요시간
- 우선순위
- 목표 완료일까지 남은 기간
- 시험일까지 남은 기간
- 남은 학습 가능시간
- 학습 유형별 실행 단위
- 사용자가 설정한 최소 학습 단위

### 기본 규칙

1. 우선순위가 높은 항목을 우선 고려한다.
2. 목표 완료일이 가까운 항목을 우선 고려한다.
3. 설정된 학습 가능시간을 초과하지 않는다.
4. 완료된 항목은 배정하지 않는다.
5. 남은 학습량이 있는 항목만 배정한다.
6. 가능한 경우 여러 학습 유형을 병행한다.
7. 강의는 강의 단위로 배정한다.
8. 문제풀이는 문제 수 단위로 배정한다.
9. 복습은 시간 단위로 배정한다.
10. 최소 학습 단위가 설정된 경우 이를 고려한다.

자동 계획은 권장안이며 사용자가 수정할 수 있다.

---

## 11. 자동 재배분 규칙

다음 변경이 발생하면 오늘 이후의 남은 일정을 재계산한다.

- 실제 학습 결과 입력
- 오늘 계획 수정
- 요일별 학습시간 변경
- 특정 날짜 예외 변경
- 우선순위 변경
- 목표 완료일 변경
- 학습 항목 추가·수정·삭제
- 시험일 변경

재계산 시 이미 완료한 학습량은 제외하고 남은 학습량만 배정한다.

앱을 다시 열었을 때 계획 조건과 학습 기록에 변경이 없으면 기존 계획을 그대로 표시한다.

---

## 12. 오늘 계획 수정

오늘의 자동 계획을 수정하는 경우 기본적으로 해당 날짜에만 적용한다.

사용자가 오늘 학습량을 줄이면 줄어든 양은 미완료 학습량으로 남긴다.

미완료 학습량은 이후 가능한 날짜에 자동 재배분한다.

오늘 계획 수정이 장기적인 계획 기준 변경을 의미하지는 않는다.

다음 항목을 변경하는 경우에는 전체 남은 일정을 다시 계산한다.

- 학습 가능시간
- 특정 날짜 예외
- 우선순위
- 목표 완료일
- 학습 항목
- 시험일

---

## 13. 실제 학습 결과 입력

학습 후 사용자가 완료한 양만 간단히 입력할 수 있어야 한다.

### 강의

- 완료 여부
- 진행률 또는 학습시간
- 선택적 실제 소요시간

### 문제풀이

- 완료한 문제 수
- 선택적 정답·오답 수
- 선택적 실제 소요시간

### 복습

- 완료 여부 또는 완료 회차
- 선택적 실제 학습시간

입력 후 앱은 다음을 수행한다.

1. 학습 항목의 진행량을 갱신한다.
2. 남은 학습량을 계산한다.
3. 이후 학습 가능시간을 계산한다.
4. 남은 학습량을 재배분한다.
5. 부족 시간과 미배정량을 갱신한다.

---

## 14. 시간 부족 시 처리

남은 학습량이 시험일까지의 학습 가능시간보다 많으면 가능한 범위까지만 계획한다.

다음 정보를 명확하게 표시한다.

- 총 필요 학습시간
- 총 학습 가능시간
- 부족한 시간
- 미배정 학습량
- 완료하지 못할 가능성이 있는 항목

예:

```text
필요 학습시간: 30시간
학습 가능시간: 20시간
부족한 시간: 10시간
```

초기 버전에서는 다음을 자동으로 수행하지 않는다.

- 사용자가 설정한 시간을 초과하여 배정
- 낮은 우선순위 항목을 시험 이후로 이동
- 학습 항목 자동 삭제 또는 제외

사용자가 직접 조건을 변경한 경우에만 다음을 허용할 수 있다.

- 학습 가능시간 증가
- 목표 완료일 변경
- 학습량 조정
- 시험일 변경
- 항목 우선순위 변경

---

## 15. 선행 항목

선행 항목 기능은 설계에는 남겨두지만 초기 버전에서는 구현하지 않는다.

초기 버전에서는 모든 학습 항목을 독립적으로 배정한다.

병행할 수 있는 항목은 선행관계를 지정하지 않고 등록한다.

이후 구현 시에는 다음 규칙을 적용한다.

- 선행 항목이 완료되기 전에는 후속 항목을 자동 배정하지 않는다.
- 후속 항목은 선행 학습 대기 상태로 표시한다.
- 선행 항목 완료 후 남은 일정에 후속 항목을 배정한다.

---

## 16. 시험 계획 상태

초기 버전은 진행 중인 시험 계획을 중심으로 구현한다.

시험일은 수정할 수 있으며, 수정 시 남은 일정은 재계산한다.

다음 상태 관리는 이후 구현한다.

- 계획 생성 전
- 일시정지
- 시험 응시 완료
- 시험 취소
- 준비 중단
- 종료된 계획 조회
- 일시정지 후 재개

---

## 17. 초기 버전 완료 기준

다음 흐름이 실제로 동작하면 초기 버전의 핵심 완료로 본다.

### 시험과 콘텐츠

- 시험명과 시험일을 등록할 수 있다.
- 시험일을 수정할 수 있다.
- 강의·문제풀이·복습 유형을 선택할 수 있다.
- 강의, 문제풀이, 복습 항목을 등록할 수 있다.
- 강의 목록을 붙여넣어 기본 정보를 파싱할 수 있다.
- 파싱 결과를 수정한 후 일괄 등록할 수 있다.
- 우선순위와 선택적 목표 완료일을 설정할 수 있다.

### 학습시간

- 요일별 학습 가능시간을 설정할 수 있다.
- 특정 날짜의 예외 시간을 설정할 수 있다.
- 0시간 휴식일을 설정할 수 있다.

### 계획

- 시험일까지의 학습 가능시간을 계산할 수 있다.
- 학습 항목의 남은 학습량을 계산할 수 있다.
- 우선순위와 목표 완료일을 반영하여 일별 계획을 생성할 수 있다.
- 콘텐츠 유형별 실행 단위로 계획을 표시할 수 있다.
- 계획 부족분과 미배정량을 표시할 수 있다.
- 사용자의 학습 가능시간을 임의로 초과하지 않는다.

### 기록과 재배분

- 강의 완료·진행률을 기록할 수 있다.
- 완료한 문제 수를 기록할 수 있다.
- 복습 완료 회차를 기록할 수 있다.
- 실제 소요시간을 선택적으로 기록할 수 있다.
- 실제 학습 결과 입력 후 남은 일정을 재배분할 수 있다.
- 오늘 계획을 일회성으로 수정할 수 있다.
- 학습시간이나 콘텐츠 조건 변경 후 일정을 재계산할 수 있다.
- 변경이 없을 때 기존 계획을 재사용할 수 있다.

## 19. 초기 버전 개발 원칙

초기 버전은 기능 수보다 다음 네 가지를 우선 검증한다.

1. 학습 항목을 쉽게 등록할 수 있는가
2. 현실적인 일별 계획이 생성되는가
3. 학습 결과를 간단히 입력할 수 있는가
4. 남은 일정이 일관되게 재배분되는가

세부 상태 관리, 선행관계, 고급 복습 기능은 핵심 흐름이 안정된 후 추가한다.
