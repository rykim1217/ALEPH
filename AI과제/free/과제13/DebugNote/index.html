Python을 처음 배우는 학습자가 코드를 직접 실행하고, 실제 오류가 발생한 경우 오류 위치·원인·힌트·수정 예시를 단계별로 확인할 수 있습니다.

연구 출발점 잘못된 오류 전제가 생성형 AI의 Python 코드 수정 행동에 미치는 영향

오류라고 단정해 바로 수정하기보다 실제 코드 상태를 먼저 확인하고, 정상 코드에는 불필요한 수정을 권하지 않으며 실제 오류가 확인된 경우에만 수정 방향을 제시하는 원칙을 반영했습니다.

          FROM RESEARCH TO APP
          
연구에서 앱으로

        

        
      

      
논문에서는 정상 Python 코드에 “오류가 있다”는 잘못된 전제를 주어도 생성형 AI가 코드 자체를 확인하고 불필요한 수정을 하지 않는 결과가 나타났습니다.

      
DebugNote는 이 결과에서 ‘오류라고 가정하기보다 실제 코드 상태를 먼저 확인한다’는 원칙을 가져왔습니다. 코드를 먼저 실행해 실제 오류 여부를 확인하고, 정상 코드에는 수정을 권하지 않으며 실제 오류가 발생한 경우에만 원인과 수정 방법을 제공합니다.

      

        
실제 코드 상태 확인→Python 코드 직접 실행

        
정상 코드의 불필요한 수정 없음→정상 실행 시 수정 제안 없음

        
실제 오류 확인 후 지원→오류 위치·원인·힌트·수정 예시 제공

      

      
그래서 DebugNote는 오류를 전제로 답을 제시하는 도구가 아니라, 먼저 실행해 확인하고 필요한 경우에만 수정을 돕는 Python 학습 도구로 설계했습니다.
