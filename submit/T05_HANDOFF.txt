1. 목표

T04 '오늘의 달러 환율' 정보판을 기반으로
'기록 전체 삭제' 기능을 추가한다.

기능 정의:
사용자가 '기록 전체 삭제' 버튼을 누르면 저장된 날짜별 환율 기록이
모두 삭제되고 화면의 기록 목록이 즉시 비워진다.


2. 현재 상태

AI A는 계획한 최대 요청 5회를 사용한 뒤 작업을 중단했다.

현재 구현 완료:
- '기록 전체 삭제' 버튼 추가
- 버튼 클릭 시 저장된 날짜별 환율 기록 삭제
- 삭제 직후 화면 목록 즉시 갱신
- 개선 기능 이름과 사용 방법 화면 표시
- AI A 작업 상태와 남은 작업을 환율 정보판 외부에 표시

GitHub의 submit/task05.html이 현재 작업본이다.
GitHub 커밋 기록에 AI A 요청 1~5의 변경 과정이 남아 있다.

현재 검사 결과: 7/10 통과


3. 실행 명령

별도 설치나 빌드가 필요 없는 단일 HTML 파일이다.

실행 방법:
1) 저장소에서 submit/task05.html을 연다.
2) 브라우저에서 task05.html을 실행한다.
3) 인터넷 연결 상태에서 환율 조회와 기록 기능을 확인한다.

최종 검증은 공개 배포 주소에서 다시 수행한다.


4. 통과한 검사

[정상 동작]

1. 통과 — 기록이 있는 상태에서 '기록 전체 삭제'를 누르면
   저장된 기록이 모두 삭제된다.

2. 통과 — 삭제 직후 새로고침하지 않아도
   날짜별 기록 목록이 즉시 빈 상태로 바뀐다.

3. 통과 — 삭제 후 새로고침해도 삭제 전 기록은 복구되지 않는다.
   페이지 자동 조회로 새로운 오늘 기록이 생성되는 것은 정상 동작이다.

4. 통과 — 삭제 후 새로 조회된 환율 기록이 정상적으로 저장되고 표시된다.


[오류 상황]

5. 통과 — 기록이 0개인 상태에서 삭제 버튼을 눌러도
   오류 없이 빈 상태가 유지된다.

6. 통과 — 삭제 버튼을 빠르게 여러 번 클릭해도
   오류 없이 정상 상태가 유지된다.

7. 통과 — localStorage의 usd-krw-daily-history-v1 값을
   비정상 데이터로 변경한 뒤 삭제를 실행해도
   저장 데이터가 삭제되고 화면이 정상 상태로 유지된다.
